# Parts Finder

Truck workshops look up parts and put together a quote. The catalogue is searchable by name or OEM number and can be narrowed by brand and condition. Every workshop authenticates with its own API token and has its own discount percentage. A quote starts as a draft that follows current prices and stock; on submit the server locks it with the unit prices and totals of that moment. Parts without stock can still be quoted and are flagged as backorders.

Decisions and their rejected alternatives are in [DECISIONS.md](DECISIONS.md); coding rules in [AGENTS.md](AGENTS.md).

## Stack

| Layer | Technology |
| --- | --- |
| Frontend | Nuxt 4, Vue 3, Nuxt UI, Tailwind CSS 4, server-side rendered |
| Backend | Laravel 13 on PHP 8.5, REST JSON API, Sanctum bearer tokens |
| Database | MySQL 8.4 (SQLite in memory for tests) |
| API contract | OpenAPI generated by Scramble, TypeScript types generated from it |
| Tooling | Docker (Sail) for the backend, Make, Pint, ESLint, Pest, Vitest, GitHub Actions |

## Getting started

Needs Docker and Node 24 with pnpm. PHP and Composer are not needed on the host: `make setup` installs the Composer packages in a throwaway container.

```bash
make setup   # .env files, Composer and pnpm packages
make up      # API, MySQL and phpMyAdmin through Sail, detached
make seed    # APP_KEY if missing, then migrate:fresh --seed
make dev     # Nuxt dev server on the host
```

Frontend on <http://localhost:3000>, API docs on <http://localhost/docs/api>, phpMyAdmin on <http://localhost:8080>.

The seeder creates two workshops. By default the frontend acts as the one without discount (`local-token-standard`). To act as the one with 10% discount, comment that line out in `frontend/.env` and uncomment `local-token-discount`.

| Command | Does |
| --- | --- |
| `make test` | Run Pest (through Sail) and Vitest |
| `make lint` | Check with Pint, ESLint and the Nuxt typecheck |
| `make format` | Fix formatting with Pint and ESLint |
| `make types` | Regenerate the OpenAPI document and the frontend types after an endpoint change |
| `make attach` | Follow the logs of the backend containers |
| `make down` | Stop the backend stack |

Run Artisan through Sail (`./vendor/bin/sail artisan ...` in `backend/`).

## Cut

Left out on purpose, to finish the required scope first:

- Part variants: see decision 4 in [DECISIONS.md](DECISIONS.md).
- Stock subtraction on submit: a quote is not an order, so submitting checks stock but never changes it, and two workshops can quote the last unit.
- Idempotent import command: the catalogue comes from `PartSeeder` and `parts.json`.
- Rate limiting and cache headers on `GET /api/parts`: not needed for a local example store.
